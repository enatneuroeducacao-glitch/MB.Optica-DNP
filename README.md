# MB.Óptica DNP

Protótipo experimental para leitura de distância naso-pupilar (DNP) usando a câmera do celular.

## Objetivo da versão de teste

- abrir a câmera frontal;
- detectar o rosto e os olhos;
- localizar os centros das pupilas;
- visualizar as marcações em tempo real;
- preparar a base para uma futura calibração em milímetros.

> **Importante:** esta primeira versão é experimental. A leitura exibida ainda não deve ser usada como medida óptica definitiva. A conversão confiável de pixels para milímetros será implementada e validada em uma etapa específica de calibração.

## Execução

O projeto é uma aplicação web estática e pode ser publicada no GitHub Pages ou Vercel.
